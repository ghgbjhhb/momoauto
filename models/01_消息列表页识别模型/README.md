## 三、核心算法与工程细节

1. **输入分辨率与模式**：
   - 使用 `imgsz=832`，矩形推理模式 (`rect=True`)。针对竖屏手机长宽比（9:16、9:20）保留最精细的字符与按键边缘。
2. **防重叠与边界安全**：
   - 自动检测底栏 Tab 顶边缘 (`tab_top_y`) 与顶栏底边缘 (`header_bottom_y`)，严格确保卡片点击点不会误触底栏图标。
3. **首尾半露卡片过滤 (`filter_edge_cards`)**：
   - 列表上下滚动时，顶部第一项和底部最后一项往往只有一半进入视野，点击易发生误触。引擎内置排序与首尾过滤逻辑。
4. **头像内假红点清洗**：
   - 针对部分用户头像本身带有红色图案的情况，限定红点有效区域为卡片右侧，彻底消除假未读告警。

## 四、如何二次微调或重新训练

当后期采集了新手机或新 UI 样式的截图后，执行以下步骤即可快速重训：

1. **准备新数据**：
   - 将新图片放入 `dataset/images/train/` 或 `val/`；
   - 对应的标注 txt 放入 `dataset/labels/train/` 或 `val/`；
2. **修改类别（如有新增）**：
   - 若要新增控件，修改 `dataset/data.yaml` 中的 `nc` 和 `names`。
3. **启动训练**：
   ```bash
   python train_10class_yolo11m.py
   ```
4. **训练关键超参数配置**：
   - 基础模型：`yolo11m.pt`
   - 初始学习率：`lr0=0.003`，余弦衰减 `cos_lr=True`
   - 边框损失权重：`box=9.0`，分布损失 `dfl=2.5`（高精定位）
   - 数据增强：Mosaic `0.1`，最后 10 轮关闭增强以收敛精度。
