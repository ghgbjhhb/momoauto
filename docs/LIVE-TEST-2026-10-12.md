## 联调发现及修复

1. 滑块没有 aria-valuenow，aria-valuetext 还会停留在旧值；改读可见数值并操作真正响应键盘的手柄。
2. 关闭开关后 Vue 会省略 aria-checked；改读 DOM checkbox.checked。
3. 菜单点击关闭后仍有短暂动画，紧接调用会找不到按钮；现在等待菜单真正隐藏。
4. 顶部提示框可能遮住侧栏图标；主按钮使用 Enter 激活，子菜单操作先等待可见。
5. 国家代码查询不带 id 返回 HTTP 500；新增 phone.countryCodes 自动绑定 id，并补充文档及回归测试。

## 证据与清理

原始 REST/WebSocket 操作记录及 JPEG 截图位于 `.local-output/live-third/`；复测位于其 `retest/` 子目录。原始记录中的 ok=true 仅表示调用与随后截图成功，是否有实际效果以上述人工核对结果为准；包含一次缺 id 的失败请求，已单独复测。

网页适配器和自动重连证据另存为该目录下的 `browser-evidence.json`；最终截图为 `verified-browser.jpg`。本地测试 40/40 通过，TypeScript 严格声明检查、实测台语法检查及 npm 打包预检通过。

Token 由当前目标 iframe 的 DOM 地址读取后传到仅本机可访问的测试进程，不打印、不写文件、不提交到仓库。测试结束关闭连接和临时 HTTP 服务，并清空内存里的凭据；网页尺寸和三个偏好开关恢复原值，关闭测试对话框，手机回到桌面。

测试程序 `scripts/live-lab.js` 不自动运行任何动作；必须显式选择固定设备并连接。它有 loopback 绑定、Origin/Host/随机会话校验及动作白名单，不是长期公网控制服务。
