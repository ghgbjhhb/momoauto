# 项目目录与维护约定

本次只整理应用和脚本代码，不修改业务操作顺序。模型、模型对应资料、登录配置和已有运行记录均保留原位；不清理模型别名或历史权重。

## 代码归属

```text
app/                    网页界面，原页面功能和文案不变
src/
  index.js              SDK 公共入口，原导入方式不变
  tools/                截图、点击、滑动、打开 MOMO 等底层工具
    momo/               新增 MOMO 应用能力：当前含首页布局校验、刷新与循环浏览
  automation/           公共桌面查找、OCR 进程、路径与命令行输出
  workflows/            10 个业务脚本的正式实现
  server/               本地 HTTP 服务和手动控制桥
  typing/               WebSocket 拼音输入与候选确认
flows/                  保留中文名称和编号的正式执行入口
python_typing/          中文分词、拼音和电脑键盘输入模块
python_workers/
  ocr/                  初始化流程 OCR、输入法候选 OCR 常驻进程
  typing/               分词及拼音计划输出进程
scripts/                启动兼容入口及原有模型辅助脚本
  dev/                  与正式控制台分开的开发工具
examples/               SDK 用法示例和旧脚本兼容入口
requirements/           按用途区分的 Python 依赖清单
docs/                   使用说明和文档索引
```

正式实现不从 `examples` 导入；新业务代码放 `src/workflows`，可复用能力放 `src/automation` 或 `src/tools`。旧文件只转发，后续修改正式实现，不维护两份业务代码。

## 入口兼容

`npm run app`、`npm run type:ws` 和 01–10 的 `npm run flow:NN` 名称保持不变。`node scripts/app-server.js`、`node scripts/ws-ime-input.js` 以及原 `examples` 脚本路径继续可用。

01–08 仍由 `flows/_common.js` 顺序执行；09“改机重置”、10“增加VPC网络”仍是独立操作，不加入“执行全部”。设备选择、执行确认、等待生成完成和失败停止逻辑未因目录整理改变。

旧的固定第一台/第三台证书入口和第三台 VPC 入口仅兼容保留，新调用应使用 `flows` 并显式指定设备 ID。原来的 `*-to-first` 实现已经迁入通用名称，不再由正式流程依赖旧文件名。

## 不搬动的目录和资料

| 路径 | 处理约定 |
| --- | --- |
| `models/` 整个目录 | 不改名、不移动、不合并、不删权重、训练集、标注或评测资料 |
| `src/tools/vision/`、模型辅助脚本、模型评测说明 | 本次保持不变 |
| `.research/`、已有模型相关 `.local-output/` 记录 | 保留原位，避免破坏模型迭代和历史引用 |
| `.env.local` | 原位保留，不输出令牌、不复制到发布包 |
| `.venv-zhtyping/` | 保留已可用的打字环境，不搬移虚拟环境 |
| `.local-output/vision-test/venv`、`site-packages` | 当前 OCR 仍可回退使用，不可当临时垃圾删除 |
| `test/`、`test-support/` | 既有文件保留；本次不新增、不运行测试套件 |

`.local-output` 只保存运行产物的约定从新代码继续执行，但旧 OCR 环境是明确的历史例外。新环境配置优先于旧路径；不要直接搬移 Python 虚拟环境，避免绝对路径和启动脚本失效。

## 依赖和部署边界

Node 依赖继续由 `package-lock.json` 管理。Python 依赖见 [运行依赖](../requirements/README.md)，根目录 `requirements.txt` 兼容原打字安装命令。YOLO 的原有 WSL 环境与模型说明不改。

包白名单包含正式服务、业务代码和 Python worker，不包含 `.env.local`、`.runtime`、虚拟环境、截图记录、研究下载或开发实测台。`models` 仍作为本机外部资产保留，不因本次整理自动打进包；当前项目不是完整商业安装器。
