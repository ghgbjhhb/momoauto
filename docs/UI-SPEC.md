# UI-SPEC · 云机控制台视觉约束

> 版本 1.1 · 2026-10-30 · 分支 `ui/refactor`
> 适用范围：`app/` 下全部页面。本文件是约束，不是建议；违反即为缺陷。

---

## 0. 这份文档怎么用

四层，缺一层就不成立：

| 层 | 内容 | 产物 | 谁来保证 |
|---|---|---|---|
| L1 | 原则（5 条，不可协商） | 本文第 1 节 | 人 |
| L2 | 令牌（角色 → 值） | `app/tokens.css` | 人 + lint |
| L3 | 组件契约（解剖 + 状态 + 场景） | `app/ui.css` | 人 + lint |
| L4 | 机器验收 | `scripts/ui-lint.js`、`scripts/ui-shot.js` | 自动 |

**判据**：执行者（人或 AI）不知道设计意图，只读本文 + `ui.css`，写出来的页面应当与参考实现属于同一系统。做不到，说明约束有洞，回来补，而不是「这次先这样」。

**参考实现**：`app/style-proof.html`。`node scripts/ui-shot.js` 生成明暗两张截图并做渲染断言。

## 1. 原则（L1）

1. **信息优先**。每个视觉元素必须能回答「它承担什么信息功能」。答不出来就删。
2. **单一强调色**。全站只有一个 `--accent`。蓝色只出现在主操作、当前选中、活跃状态三处。
3. **层次靠明度差和边框，不靠投影**。静态卡片零阴影；阴影只表达「浮起来了」。
4. **零装饰**。没有渐变、没有彩色光晕、没有侧边色条、没有装饰性图标、没有 emoji。
5. **状态完整**。只做默认态等于没做完。

违反第 1 条的症状：页面很满但读不出重点。
违反第 2 条的症状：屏幕上 3 个以上蓝色元素，用户不知道点哪个。
违反第 3 条的症状：卡片像塑料片浮在桌面上（彩色 `rgba(主色,.15)` 阴影是典型）。
违反第 5 条的症状：脚本跑一半失败，界面没有任何变化。

## 2. 令牌（L2）

### 2.1 铁律

- **唯一真源是 `app/tokens.css`**，其余 CSS 不允许出现 hex、`rgb()`、`hsl()`、`oklch()`。
- **所有令牌挂在 `:root[data-ui="v2"]` 下**。引用 `tokens.css` 的页面必须在 `<html>` 上写 `data-ui="v2"`，否则令牌不生效。这条隔离是为了防止和旧样式表（`styles.css` / `theme-*.css`）里 7 个同名变量互相覆盖。
- 组件只能消费**角色令牌**（`--bg-*` / `--text-*` / `--border*` / `--accent*`）。
- 换主题只改 `[data-theme]` 里的值，组件层零改动。

### 2.2 角色表

| 角色 | 用途 | 禁止用于 |
|---|---|---|
| `--bg-page` | 页面底 | 卡片 |
| `--bg-surface` | 卡片、面板、输入框 | 页面底 |
| `--bg-subtle` | 表头、日志块、骨架、次级填充 | 大面积区块背景 |
| `--bg-raised` | 模态、下拉、浮层 | 静态卡片 |
| `--bg-hover` | 行悬停 | 选中态 |
| `--bg-selected` | 选中行 | 悬停 |
| `--bg-selected-hover` | 选中行再悬停 | 普通悬停 |
| `--bg-overlay` | 模态遮罩 | 任何实体背景 |
| `--text-1` | 标题、正文、单元格 | 辅助信息 |
| `--text-2` | 标签、表头、日志正文 | 大段正文 |
| `--text-3` | 时间戳、提示、占位、序号 | 正文 |
| `--text-on-accent` | accent 底色上的文字 | 其他底色 |
| `--border` | 默认分隔、卡片边框 | 需要强调的边界 |
| `--border-strong` | 输入框、模态、强调边界 | 普通分隔线 |
| `--accent` | 主操作、选中、活跃 | 大面积填充、图标装饰 |
| `--ok/warn/danger/info` + `-soft` | 状态徽章、日志级别 | 正文文字颜色 |

### 2.3 排版角色表（每个角色只有一个答案）

| 角色 | 字号 | 字重 | 颜色 | 行高 |
|---|---|---|---|---|
| 页面标题（header） | `--fs-16` | 500 | `--text-1` | tight |
| 区块/卡片标题 | `--fs-14` | 600 | `--text-1` | tight |
| 正文、表格单元格 | `--fs-13` | 400 | `--text-1` | normal |
| 表单标签 | `--fs-12` | 500 | `--text-2` | normal |
| 表头 | `--fs-12` | 500 | `--text-2` | none |
| 辅助说明、时间戳、提示 | `--fs-12` | 400 | `--text-3` | relaxed |
| 徽章 | `--fs-12` | 500 | 语义色 | none |
| 等宽数字、设备 ID | `--fs-11` | 400 | `--text-3` | none |
| 日志 | `--fs-12` | 400 | `--text-2` | relaxed |

**层级靠字号差（16 → 14 → 13 → 12）、颜色差（text-1 → text-2 → text-3）和字重差（标题 600 / 正文 400）。** 500 只用于按钮、徽章、表单标签这类控件文字；正文不允许 500。

11px 仅用于拉丁字母、数字、设备 ID、序号。**中文最小 12px。**

### 2.5 间距语义表（哪个值用在哪种关系）

| 关系 | 值 | 例子 |
|---|---|---|
| 图标与文字 | `--sp-4` / `--sp-6` | 按钮内图标、徽章内圆点 |
| 同一字段内（标签 → 输入 → 提示） | `--sp-6` | 表单字段内部 |
| 并排元素之间 | `--sp-8` | 按钮组、工具条子项 |
| 表单字段之间 | `--sp-12` | `.ui-form-grid` 的 gap |
| 卡片之间、区块内子块之间 | `--sp-16` | 页面网格 gap |
| 区块之间（跨卡片） | `--sp-20` / `--sp-24` | `.ui-main` 的 padding 与 gap |

### 2.6 结构值 vs 视觉值

| 类型 | 例子 | 规则 |
|---|---|---|
| 视觉值 | 颜色、字号、字重、行高、间距、圆角、阴影、动效、z-index、固定高度 | **必须**走令牌，lint 阻断 |
| 结构值 | 侧栏 300px、`minmax(220px,1fr)`、`aspect-ratio: 9/16`、百分比宽度、`calc()` | 允许字面量，只能出现在布局类里，同类只写一次 |

### 2.7 三层明度差（可验收）

深色下三层背景必须**肉眼可分辨**，判据是相邻层亮度差：

| 层 | 浅色 | 深色 |
|---|---|---|
| 页面 | `#eef0f4` | `#0b0b0d` |
| 卡片 | `#ffffff` | `#17171a` |
| 浮层 | `#ffffff` + `--border-strong` + `--shadow-3` | `#232328` |

浅色下卡片与页面靠明度差，浮层靠边框 + 阴影；深色下三层靠明度差。**不允许出现两层同值却要求用户区分的情况。**

| 状态 | 按钮 | 输入 | 行 |
|---|---|---|---|

| 只读 | — | `--bg-subtle` 底，无聚焦环 | — |
| 加载 | 前置 12px 旋转环 | — | — |
| 错误 | — | 边框 danger + 下方 12px 红字 | — |

### 3.3 何时用 / 何时不用

**视觉分区**的定义：一张卡片、一个工具条、或页头操作区，各算一个分区。

| 组件 | 用 | 不用 |
|---|---|---|
| 主按钮 | **每个视觉分区最多 1 个** | 行内重复操作、次要动作 |
| 次按钮 | 与主操作并列的替代路径 | 列表行内（用 ghost） |
| 危险按钮 | 模态内的不可撤销确认、工具条上的批量删除 | 普通删除确认以外的场景 |
| 徽章 | 状态 | 分类标签、数量、版本号 |
| 模态 | 需要中断流程的确认 | 表单编辑（用页面或抽屉） |
| 卡片 | 内容成组且边界有意义 | 为了「看起来整齐」而套卡片 |

**页面级与分区级的关系**：页面主操作（如「执行全流程」）占页头或主工具条的一个分区；筛选区的「查询」若同时是主按钮，则该页出现 2 个蓝色主按钮，此时把「查询」降为次按钮，保留页面主操作。

**禁止卡片套卡片。** 需要分组用间距和分隔线。

**模态按钮顺序**：次要动作在左，主/危险动作在右。危险确认框的初始焦点落在「取消」，且确认按钮默认禁用，需输入确认文本才启用。

### 3.4 数据展示

- 含数字的列一律右对齐，`font-variant-numeric: tabular-nums`（`ui.css` 已全局设置）。
- **单位提到表头**（`耗时 (s)`），单元格只放数字，避免 `42.6s` / `1m 12s` 单位长度不一导致小数点错位。
- 空值统一 `—`（U+2014），不用「无」「N/A」「-」。
- 时长 `42.6`（秒）；超过 60s 写 `72.4` 或换算到分钟并在表头注明。
- 尺寸 `720×1280`（乘号，不是字母 x）。
- **禁止斑马纹**，用 hover 与选中态区分行。
- 状态列只放徽章，不放彩色文字。
- 表格必须包在 `.ui-table-wrap` 内（横向滚动兜底）；超过 50 行才分页。
- 文本列必须显式声明：默认 `nowrap + ellipsis`，需要换行的列加 `.is-wrap`。

### 3.5 状态词表（状态 → 令牌 → 文案，唯一映射）

| 业务状态 | 令牌 | 文案 | 说明 |
|---|---|---|---|
| 成功 / 完成 | `--ok` | 完成 | |
| 进行中 / 运行中 | `--info` | 运行中 | 不用 accent，避免和主操作撞色 |
| 排队 / 待执行 | 默认（`--bg-subtle` + `--text-2`） | 排队 | 中性，不占用语义色 |
| 警告 / 需确认 | `--warn` | 需确认 | |
| 失败 / 错误 | `--danger` | 失败 | |
| 部分成功 | `--warn` | 部分成功 | 文案必须带数量：`成功 6 / 失败 2` |
| 已取消 | 默认 | 已取消 | 不是错误，不用 danger |
| 超时 | `--danger` | 超时 | |
| 离线 | 默认 | 离线 | 设备不可用是中性事实，不是错误 |

### 3.6 文案

| 项 | 规则 | 反例 |
|---|---|---|
| 术语 | 统一用「设备」（`deviceId`），不用「云机 / 云手机」混称 | 「云机 SF-03 设备已连接」 |
| 按钮 | 动词或动词+宾语，2–5 字 | 「确定」含义不明 |
| 标点 | 不用感叹号，不用「请稍候」「正在努力」这类空话 | 「请稍候…」 |
| 错误 | 现象 + 位置 + 下一步 | 「操作失败」 |
| 时间 | 24 小时制 `HH:mm:ss`，本地时区；跨天必须带日期 | `03:12` 缺秒 |

### 3.7 空态三型（文案不同，不能混用）

| 类型 | 触发 | 文案结构 | CTA |
|---|---|---|---|
| 无数据 | 从未创建过 | 说明这里会有什么 + 怎么开始 | 主操作（lg） |
| 无匹配 | 筛选/搜索无结果 | 说明筛选条件无结果 + 建议放宽 | 「清除筛选」（次按钮） |
| 无权限 | 角色不足 | 说明需要什么权限 + 找谁 | 无 CTA，或「联系管理员」 |

**「暂无数据」四个字不是空态文案。**

### 3.8 加载场景矩阵

| 场景 | 表现 | 禁止 |
|---|---|---|
| 首屏加载 | 表格区域显示 3–5 行骨架，表头保留 | 整页白屏、整页 spinner |
| 局部刷新（筛选、翻页） | 保留旧数据 + 顶部 2px 进度条，或表格区半透明遮罩 | 清空表格再重新出现（CLS） |
| 提交中（按钮触发） | 按钮进入 loading，文字不变，禁用重复点击 | 全屏遮罩 |
| 长任务（脚本执行） | 状态徽章变「运行中」+ 日志流式追加 | 模态进度框阻塞操作 |

骨架只用于**内容区**，不用于按钮内、行内文字中间、图标位置。

### 3.9 图标

- 只有一套线性图标，16 / 20 两档，`stroke-width: 1.5`，`currentColor`。
- 纯图标按钮必须有 `aria-label` 和 `title`。
- **禁止 emoji**。当前 `app/` 下 157 处 emoji 待迁移（其中 HTML 内 52 处），迁移时按「能不能删」优先，不能删的换线性图标。

### 3.10 动效

- 只允许 `opacity` / `transform` / 颜色类（`background-color`、`border-color`、`color`、`box-shadow`）过渡。
- 禁止对几何属性做动画（`width`、`height`、`top`、`margin`）。
- 禁止 `scale()` 放大、`skew`、bounce / elastic 缓动。
- 必须提供 `prefers-reduced-motion` 降级：过渡压到 1ms，骨架停止闪烁，**但加载旋转保留**（否则用户看不出正在执行）。

## 4. 机器验收（L4）

```bash
node scripts/ui-lint.js           # 写法检查，已迁移文件必须 0 违规
node scripts/ui-lint.js --legacy  # 附加旧样式表基线统计
node scripts/ui-shot.js           # 渲染断言 + 明暗截图
```

### 4.1 迁移标记

**页面 `<html>` 上有 `data-ui="v2"` 即视为已迁移**，lint 对该页启用全部阻断规则；没有该属性的页面记入「待迁移基线」，不阻断但会被计数。

这条让「宣称已迁移」和「真的过了检查」变成同一件事，避免出现「lint 全绿但其实没扫这个页面」。

### 4.2 lint 规则

| 规则 | 判定 |
|---|---|
| `COLOR` | 任何 hex / rgb / hsl / oklch 字面量（`tokens.css` 除外，含 `border`、`outline`、`text-shadow` 简写） |
| `UNDEFINED_TOKEN` | `var(--x)` 未在 `tokens.css` 定义 |
| `FONT_SIZE` / `FONT_WEIGHT` / `LINE_HEIGHT` | 越界或非令牌 |
| `RADIUS` | 不在 4 / 6 / 8 / 999 |
| `SPACING` | padding / margin / gap 出现字面量 |
| `HEIGHT` | ≥20px 的固定高度未用 `--h-*` / `--icon-*` |
| `SHADOW` | 非 `--shadow-*` / `--focus-ring` |
| `MOTION` | 过渡了非颜色 / 非 transform 属性 |
| `TRANSFORM` | 出现 `scale` / `skew` |
| `EFFECT` | 出现 `backdrop-filter` / `filter` |
| `ZEBRA` | `nth-child(even/odd)` 里设置背景 |
| `ACCENT_BAR` | `border-left/right` ≥2px 且颜色为 accent |
| `IMPORTANT` | 出现 `!important`（`prefers-reduced-motion` 块除外） |
| `GRADIENT` | 出现 `gradient(` |
| `FONT_FAMILY` | 非 `var(--font-sans/mono)` |
| `Z_INDEX` | 非 `var(--z-*)` |
| `EMOJI` | HTML/JS 出现 emoji（`✓ ✗ ★ ☆` 除外） |
| `INLINE_STYLE` | 内联样式出现颜色或字面量间距 |
| `LINK_LEGACY` | 页面仍在引用 `styles.css` / `theme-*.css` |
| `DATA_UI` | 引用 `tokens.css` 但 `<html>` 缺 `data-ui="v2"` |

白名单从 `tokens.css` 反推：改令牌，规则自动跟着变；令牌改名不会造成误报。

### 4.3 渲染断言（`ui-shot.js`）

页面返回 200、样式表 ≥2、`--accent` 非空、`data-ui="v2"`、body 背景不透明、主题切换生效、1024/640 无横向溢出、无 console error / 404。任一项失败即退出码非零。

### 4.4 截图 rubric（给非专业验收人）

看截图逐条回答是/否，有一项「否」就不通过：

1. 每个分区是不是只有**一个**蓝色按钮最显眼？
2. 标题、正文、辅助文字是不是**一眼分出三层**？
3. 数字列是不是**个位对齐**（单位是否在表头）？
4. 有没有任何元素带**彩色阴影或发光**？
5. 深色下能不能**一眼分出**页面 / 卡片 / 浮层三层？
6. 有没有两个同类控件**高度不一致**？
7. 有没有大段留白**说不出原因**？
8. 有没有空占位方块（没有内容却存在的装饰容器）？

## 5. 与原 spec 的偏离（必须知道为什么）

原始提案是营销落地页语境，直接套到控制台会出问题。以下是有意偏离。

| # | 原 spec | 本 spec | 理由 |
|---|---|---|---|
| 1 | 只用 Geist + JetBrains Mono，禁止 system-ui / Roboto | 系统字体栈（含 PingFang / 微软雅黑） | CSP 为 `font-src 'self' data:`，仓库内 0 个 `@font-face`，外部字体全部被拦。要 Geist 必须自托管 woff2 并改 CSP |
| 2 | 深色单主题，不做浅色 | 双主题，角色/值分离 | 现有 theme-a / theme-b 在切换；白天明亮环境看日志需要浅色 |
| 3 | 禁止 px，出现即违规 | 区分视觉值（必须令牌）与结构值（允许字面量） | 侧栏 300px、`minmax(220px,1fr)` 无法令牌化；一刀切会导致规则整体被无视 |
| 4 | 字重 400 / 600 / 700 | 400 / 500 | 深色底上 600+ 光学加粗，13px 处会糊 |
| 5 | 最小字号 13px | 11px（仅拉丁/数字）/ 12px（中文） | 控制台 90% 文字在 11–13px |
| 6 | 动效只允许 opacity / transform | 增加颜色类过渡 | 按钮 hover 背景渐变是正常交互；该禁的是几何属性和 scale |
| 7 | `rounded.full: 9999px` | 999，仅限圆形元素 | 药丸形按钮是「AI 塑料感」高发区 |
| 8 | 组件只有 button / card / input | 12 类表面 | 控制台的表格、徽章、步骤、日志、空态占了 70% 的画面 |

其余纪律（单一强调色、无硬编码、层次靠明度、禁侧边色条、禁渐变、禁 emoji）原样保留。

## 6. 反模式清单

出现任意一条即判定为「AI 塑料感」，必须重做。

| # | 模式 | 替代 | 机器可查 |
|---|---|---|---|
| A1 | 紫蓝 / 粉紫渐变，或白底紫渐变 | 纯色；层次用 `--bg-subtle` | `GRADIENT` |

| A4 | 卡片套卡片套卡片 | 间距 + 分隔线 | 人审 |
| A5 | 所有卡片同尺寸等分网格 | 按内容权重分级 | 人审 |

| A7 | 所有可交互元素都 `scale(1.05)` + 阴影增强 | 分层反馈：链接变色、按钮背景变化、整行高亮 | `TRANSFORM` |

## 7. 迁移规则

1. **新页面**：`<html data-ui="v2">` + 只引 `tokens.css` + `ui.css`。
2. **旧页面**：一次迁一个，迁完删掉旧 CSS 引用和页面私有 `<style>`，**不允许两套并存**（并存就是下一次漂移的起点，且会互相覆盖同名令牌）。
3. 顺序：`admin.html`（表格最多，最容易看出差别）→ `index.html` → `login.html`。
4. 每个页面迁完必须：`ui-lint` 0 违规 + `ui-shot` 渲染断言通过 + 明暗两张截图 + rubric 8 条全过。
5. 迁移期间不改业务逻辑：只改 class 名和结构，不改数据流。

### 接管层（Phase 1，仅 index.html）

首页已有 143 个类名、3000 行结构样式，一次性重写风险过高。因此分两步：

| 阶段 | 做法 | 判定 |
|---|---|---|
| Phase 1（已完成） | 保留 `theme-b.css` 作**结构层**，新增 `console.css` 把旧类名映射到令牌（颜色/字号/圆角/阴影/高度），不改布局 | 页面加 `data-ui="v2"`，lint 对该页阻断；`LINK_LEGACY` 记为待办不阻断 |
| Phase 2（待做） | 逐个把 markup 换成 `ui.css` 的组件，删除 `console.css` 对应规则，最终移除 `theme-b.css` | `LINK_LEGACY` 清零 |

`console.css` 的约束与 `ui.css` 相同：**只消费令牌，零字面量颜色**。它必须随迁移单调变短，不允许新增规则。

## 8. 完成定义

一个页面算「迁移完成」，当且仅当：

- [ ] `<html data-ui="v2">`，且不再引用 `styles.css` / `theme-*.css`
- [ ] `node scripts/ui-lint.js` 0 违规
- [ ] `node scripts/ui-shot.js` 渲染断言通过，明暗两张截图 rubric 8 条全过
- [ ] 组件只来自 `ui.css`，没有页面私有的按钮/卡片样式，没有内联样式
- [ ] 没有 emoji 图标
- [ ] 交互组件具备 §3.2 规定的状态数
- [ ] 文案符合术语表、状态词表、空态三型
